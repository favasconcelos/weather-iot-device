# Hardware

This folder will hold the optional custom PCB:

- KiCad project
- schematic PDF
- Gerber files for JLCPCB/PCBWay
- BOM (bill of materials)
- assembly notes

## Status

Not started. Version 1 uses off-the-shelf modules and wires.

The plan is in [docs/10-optional-pcb.md](../docs/10-optional-pcb.md).

## Why wait?

The PCB is a refinement, not a rescue. Build and test the circuit on a
breadboard first. Then move the proven circuit to a board.
